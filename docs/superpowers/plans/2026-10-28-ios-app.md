# XFrame iOS app Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一個只給使用者自己用的 iPhone app：從 X / Threads 的分享選單一步進來，依氛圍挑樣式，輸出 9:16 圖片或影片，經 iOS 分享選單發到 IG 限動。

**Architecture:** 在 xframe repo 新增第三個組建目標 `app/`（與 `web/`、擴充功能並列），共用 `src/` 的卡片、解析、匯出程式；app 專屬的設定、氛圍、UI 全放在 `app/`。用 Capacitor 包成 iOS app，原生 HTTP 取代 CORS 受限的 fetch，Swift 寫分享延伸功能。網頁版與擴充功能的行為不變：所有共用程式的新能力都以「預設關閉」的選項加入。

**Tech Stack:** TypeScript、Preact、Vite、Vitest＋happy-dom（既有）；Capacitor 7（`@capacitor/core`、`@capacitor/ios`、`@capacitor/app`、`@capacitor/filesystem`、`@capacitor/share`）；Swift（Share Extension；必要時 AVFoundation 外掛）；Xcode 27.1。

**Spec:** `docs/superpowers/specs/2026-10-28-ios-app-design.md`

## Global Constraints

- 只支援 X 與 Threads。不做微博、小紅書。
- 內文絕不截斷——最高原則。任何縮放只縮整張貼文卡與字級，不截字。
- app 輸出畫布固定 9:16（1080×1920）。媒體（圖片與影片）保持原始比例，不放大、不裁切。
- 太高放不下時整張貼文卡等比縮小，周圍露出背景紙張。
- 字體只有兩種：文學／雜誌感用 `"Hiragino Mincho ProN", "Songti TC", serif`；其餘用 `"PingFang TC", system-ui, sans-serif`。
- 網頁版（`npm run build:web`）與擴充功能（`npm run build`）行為不變：`src/platforms/index.ts` 的 `ADAPTERS` 維持 `[xAdapter]`；`STYLE_PRESETS`、`FONTS`、`DEFAULT_SETTINGS`、比例選項不改。
- `threadframe-web` repo 不動，只讀取、移植其解析邏輯。
- 從分享選單選了 app 之後直接進主 app、卡片已在產生，中間沒有額外點擊。
- 輸出經 iOS 分享選單；不使用 Instagram Stories URL scheme。
- Bundle ID `studio.gariber.xframe`，分享延伸 `studio.gariber.xframe.share`，URL scheme `xframe`，顯示名稱 `XFrame`（Claude 的判斷）。
- 每個任務結束時 `npm test` 全數通過。

## Review Focus

1. **分享進來的文字不只是乾淨網址**：X 會給 `https://x.com/u/status/123?s=46&t=…`；Threads 會給 `https://www.threads.com/@u/post/CODE?xmt=…`、`threads.net`，或「內文＋網址」混在一起的純文字。應該都抽得出正確網址。→ Task 4 的 `extractShareUrl` 測試。
2. **Threads 擋在登入牆後的貼文**（敏感、私人、已刪除）：應顯示「Threads 不讓未登入讀取這則」的明確說明，不能顯示空白卡片或首頁推薦貼文。→ Task 3 的 `refused` 測試。
3. **app 已開著時又分享一則進來**：新貼文取代目前那張，不疊兩張、不卡在舊的。冷啟動與熱啟動都要能帶入網址。→ Task 9 的測試。
4. **直影片＋長內文**：內文全部出現、影片完整不裁，貼文卡縮小但仍在 9:16 內。→ Task 5 的測試。
5. **沒有音軌的影片（X 的 GIF 就是無聲 MP4）**：匯出成功、不因找不到音軌而失敗。→ Task 8 的測試。

## File Structure

```

  index.html, main.tsx       入口

test/app/*.test.ts(x)        app 測試
test/parse/threads.test.ts   Threads 解析
test/fixtures/threads-*.html Threads 測試頁（以 Googlebot UA 用 curl 擷取）
```
