# 商店截圖 — 待擷取

Chrome Web Store 要求 1280×800 或 640×400 PNG，至少一張。

## 在哪裡拍

**在已安裝擴充功能的瀏覽器上，直接於 x.com 拍攝。**

不需要 Node、不需要原始碼、不需要開發預覽頁 —— 真實使用畫面比預覽頁更有
說服力，那也是使用者實際會看到的東西。

## 拍哪四張

| 檔名 | 內容 |
|---|---|
| `01-editor.png` | 面板開著，卡片預覽 + 右側控制項 |
| `02-backgrounds.png` | 背景選擇區展開，40 張縮圖可見 |
| `03-quoted.png` | 一則含引用推文的卡片 |
| `04-result.png` | 匯出的成品圖 |

視窗調成 1280×800，或拍完裁切至該尺寸。

## 注意

別在截圖裡露出鎖推帳號的內容或任何私人資訊 —— 商店頁面是公開的。
挑公開帳號的推文來拍。
